- [星明かりの道しるべTRPG ルールブック（PDF）](星明かりの道しるべTRPG_ルールブック.pdf)
  - 基本ルール、判定、戦闘、キャラクター運用、リプレイについてまとめたPC向け資料
- [星みちTRPG 戦闘の手引き 早見版 PC向け（PDF）](星みちTRPG_戦闘の手引き_早見版_PC向け.pdf)
  - 攻防の流れ、防御、割り込み、成功段階、HP・APを図解した戦闘早見表
- [星明かりの道しるべTRPG PC向け世界観共有（PDF）](星明かりの道しるべTRPG_PC向け世界観共有.pdf)
  - 冒険者、依頼、モンスター、魔法、傷など、プレイ開始前に共有する世界観資料
- [キャラクター設定一覧](../キャラクター設定/README.md)
  - シーリスと、公開を承認されたPCの人物設定、現在状態、冒険履歴
- [公開キャラクターシート用テンプレート](../キャラクター設定/公開キャラクターシート用テンプレート完全版.md)
  - 新しい公開プロフィールを同じ構成で作成するための完全版テンプレート
- [星みちTRPG キャラクタービルドシミュレーター](https://sealicealtair.github.io/hoshimichi-character-sheet-builder/)
  - ポイント、装備、スキルを入力し、共有用Markdownを作る補助ツール

## 資料の境界

- キャラクター設定は、公開を承認された人物情報だけを掲載します。
- ビルドシミュレーターは入力と試算の補助ツールであり、ルール正本ではありません。
- 入力内容やツールの出力は、非公開正本へ自動反映されません。
- 物語進行中の敵の内部値、未発見能力、秘密の目的、未公開の固有能力は掲載しません。
